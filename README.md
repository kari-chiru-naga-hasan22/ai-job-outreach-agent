# 🚀 Universal Job & Internship Talent Scout

An autonomous Web Application and Talent Scout that searches the internet for verified **PAID** engineering internships and jobs across **Embedded Systems, PCB Design, Hardware, VLSI, AI, and Software** with verified stipends and direct executive **LinkedIn points of contact (HR, Technical Lead, Founder/CEO)**.

---

## ⚡ Quick Start

### 1. Configure Environment Variables
Copy `.env.example` to `.env` and add your OpenRouter API key:

```bash
OPENROUTER_API_KEY=sk-or-v1-your-key-here
OPENROUTER_MODEL_ID=meta-llama/llama-3.3-70b-instruct
PORT=8000
```

### 2. Launch the Web Application
```powershell
python start_web.py
```
This starts the FastAPI backend server and automatically opens `http://localhost:8000` in your web browser.
